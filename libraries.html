.row groups columns, .g-3 sets gutters, and col-12 col-md-6 applies both column classes to the same element. Each card takes a full row on a phone and half a row from the md breakpoint onward. The card, badge, spacing, and button styles come from the Bootstrap stylesheet. The accordion uses the Bootstrap bundle to update its expanded state.

Inspect the Bootstrap imports and markup

Load Bootstrap CSS before your custom CSS and use the matching version of its JavaScript bundle. Copy the full CDN tags from the official starter to include integrity hashes.

<!-- In the head -->
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.9/dist/css/bootstrap.min.css">
<script defer
        src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.9/dist/js/bootstrap.bundle.min.js"></script>
<div class="row g-3">
  <div class="col-12 col-md-6">
    <article class="card h-100">
      <div class="card-body">
        <h4 class="card-title h5">Garden planting</h4>
        <a class="btn btn-primary" href="#garden-details">View event details</a>
      </div>
    </article>
  </div>
  <!-- Add a second .col-12.col-md-6 here. -->
</div>
<button type="button" data-bs-toggle="collapse"
        data-bs-target="#garden-location" aria-controls="garden-location"
        aria-expanded="false">
  Where do we meet?
</button>
<div class="collapse" id="garden-location">Meet at the south entrance.</div>

Inter uses a sans-serif fallback, Playfair Display uses a serif fallback, and IBM Plex Mono uses a monospace fallback. Notice how the headline and paragraph wrap as the letter shapes change. Request the weights you actually use and keep system fallbacks so the text stays readable while the web font loads.

Inspect the font link and fallback stack 
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&amp;display=swap">
.font-sample {
  font-family: Inter, system-ui, sans-serif;
  font-weight: 400;
}
.sample-headline { font-weight: 700; }

Google Fonts CSS API

The font request fails. Which family does the browser try after Inter?

It tries system-ui, then the browser’s generic sans-serif family. A cache or network failure is easy to check in DevTools Network.

Toggle the sample bookmark with a click or the Space key.

Font Awesome class names identify the style and the icon. Here the icons next to text are decorative, so they use aria-hidden="true". For the icon-only bookmark, a visually hidden label names the control and a native checkbox exposes its checked state.

Inspect the stylesheet and icon markup 
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/@fortawesome/fontawesome-free@7.3.1/css/all.min.css">

<i class="fa-solid fa-location-dot" aria-hidden="true"></i> Location

<a href="https://github.com/">
  <i class="fa-brands fa-github" aria-hidden="true"></i> GitHub
</a>

<input class="visually-hidden" type="checkbox" id="bookmark">
<label for="bookmark">
  <i class="fa-regular fa-bookmark" aria-hidden="true"></i>
  <span class="visually-hidden">Bookmark the sample event</span>
</label>

Font Awesome icon markup

How does a screen reader know what the bookmark control does?

It reads the label “Bookmark the sample event,” which is connected to the checkbox through matching for and id values. It also reports whether the checkbox is checked.
